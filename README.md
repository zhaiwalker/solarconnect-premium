# Solarconnect

Премиальная адаптивная главная страница Solarconnect с анимациями и полным каталогом из 12 типовых комплектов.

**Сайт:** [solarconnect-premium-20260908.vercel.app](https://solarconnect-premium-20260908.vercel.app/)

## Запуск

`npm install` → `npm run dev`

Сборка: `npm run build`. Проверка типов: `npx tsc --noEmit`.

## Содержание

Данные, контакты, цены, состав комплектов и фотографии взяты с https://solarconnect.kz/ 8 сентября 2026 года. Каталог: `src/plans.json`. Перед коммерческим использованием цены следует актуализировать. Данные о результатах и гарантиях воспроизведены по источнику, независимая проверка не проводилась.

Статьи и дополнительные страницы открываются на существующем solarconnect.kz. Это новая главная страница, а не перенос всех внутренних страниц. Действующий домен не изменялся.

## Заявки

## Интерфейс

React, TypeScript, Vite, Motion, Radix Dialog/Tabs, Phosphor, локальный Manrope с кириллицей. Переключение тем, адаптация под телефон, поддержка reduced motion, управление диалогами и табами с клавиатуры.
