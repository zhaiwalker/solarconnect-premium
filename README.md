# Solarconnect

Премиальный сайт Solarconnect с разделами оборудования Deye, B2B-заявками и 12 типовыми решениями солнечных станций.

**Сайт:** [solarconnect-premium-20260908.vercel.app](https://solarconnect-premium-20260908.vercel.app/)

## Запуск

`npm install` → `npm run dev`

Сборка: `npm run build`. Проверка типов: `npx tsc --noEmit`.

## Содержание

Данные, контакты, цены, состав комплектов и фотографии взяты с https://solarconnect.kz/ 8 сентября 2026 года. Каталог: `src/plans.json`. Перед коммерческим использованием цены следует актуализировать. Данные о результатах и гарантиях воспроизведены по источнику, независимая проверка не проводилась.

Каталог, страницы товаров, партнёров, доставки и поддержки находятся внутри нового сайта. Статьи остаются на solarconnect.kz. Действующий домен не изменялся.

## Заявки

Форма расчёта станции готовит сообщение на WhatsApp компании +7 771 316 9033. Оформление заказа и B2B-форма сохраняют заявки в подключённой базе и передают их CRM через серверный webhook. При работе без серверного хранилища используется явное продолжение в WhatsApp: посетитель проверяет и отправляет сообщение самостоятельно.

## Магазин и управление

`/catalog` — поиск и фильтры; `/product/:slug` — товар; `/cart` — корзина; `/compare` и `/favorites` — сравнение и избранное; `/partners` — B2B; `/admin` — управление.

Настройка сервера, валюты, CRM и панели: [SHOP_SETUP.md](SHOP_SETUP.md). Проверки: `npm test` и `npm run build`.

## Интерфейс

React, TypeScript, Vite, Motion, Radix Dialog/Tabs, Phosphor, локальный Manrope с кириллицей. Переключение тем, адаптация под телефон, поддержка reduced motion, управление диалогами и табами с клавиатуры.
